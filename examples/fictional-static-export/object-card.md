# Object card — ExportKit (fictional example)

> **Этот pack полностью вымышлен. Название ExportKit, URLs `example.com`, роли, наблюдения и числа существуют только для демонстрации структуры. Это не исследование реальной компании, рынка или клиента.**

## Исследовательская единица

> **Независимый веб-разработчик, которому нужно передать небольшой сайт клиенту без ежемесячной подписки на конструктор, сейчас вручную экспортирует код или оставляет сайт на платформе. Вымышленный ExportKit предлагает разовый перенос в статический сайт с настройкой форм.**

| Поле | Запись |
|---|---|
| Объект | ExportKit: вымышленный разовый перенос лендинга из конструктора в статический HTML. |
| Роль / buyer | Независимый веб-разработчик; конечный клиент оплачивает разовую передачу сайта. |
| Ситуация | Клиент хочет убрать recurring fee либо забрать сайт на свой хостинг. |
| Работа / потеря | Сохранить работающий сайт и формы без ручного переписывания. |
| Current alternative | Ручной HTML rebuild, оставление сайта на builder-платформе, миграционная услуга. |
| Claim объекта | Сокращает время и риск передачи по сравнению с ручной миграцией. |
| Unit of value | Один перенесённый небольшой сайт. |
| Риск, который хотят принять | Ограниченный доступ к веб-разработчикам, которым нужна именно передача сайта. |
| Входные источники объекта | Вымышленные demo/pricing page; synthetic examples независимых сигналов категории. |

## Границы

Эта демонстрация не оценивает full website builder, hosting service или настоящий продукт под названием ExportKit. Private data в ней не поставляется; в реальном run владельцу стоило бы предоставить минимальные обезличенные данные о completed transfers, support time и invoices только после того, как внешний контур определит конкретный evidence gap.
