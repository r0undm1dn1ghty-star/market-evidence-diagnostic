# Object card — Skyeng

## Исследовательская единица

> **Взрослый или родитель школьника, которому нужен результат в иностранном языке (работа, переезд, ЕГЭ), сейчас пробует приложения-тренажёры или репетиторов по сарафану. Skyeng предлагает онлайн-уроки 1-на-1 с платформой и гарантированным расписанием.**

| Поле | Запись |
|---|---|
| Объект | Skyeng: онлайн-школа языков, модель оплаты за урок (от 987 ₽/урок по акции до 1590 ₽ стандарт). |
| Роль / buyer | Взрослый ученик или родитель; платит за пакет уроков. |
| Ситуация | Нужен измеримый прогресс в языке без поиска частного репетитора. |
| Работа / потеря | Не потерять деньги на неэффективных занятиях и не бросить обучение. |
| Current alternative | Частный репетитор, бесплатные приложения (Duolingo), групповые курсы, YouTube. |
| Claim объекта | 89% учеников используют язык в жизни через 30 уроков; платформа лучше репетитора. |
| Unit of value | Оплаченный урок с преподавателем на платформе. |
| Риск, который хотят принять | Удержание учеников в подписочной модели при росте цен и конкуренции ИИ-репетиторов. |
| Входные источники объекта | skyeng.ru (цены, программы), независимые обзоры, отзывы. |

## Границы

- Не является объектом исследования: корпоративное обучение B2B-подразделения.
- Private data недоступны: выручка, retention когорт, маржа урока, доля рынка.
- Что видно снаружи: публичные цены, программа, счётчики учеников, отзывы.
