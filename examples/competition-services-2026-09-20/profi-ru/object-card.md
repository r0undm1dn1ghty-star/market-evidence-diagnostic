# Object card — Profi.ru

## Исследовательская единица

> **Домохозяйство или малый бизнес, которому нужен проверенный специалист (репетитор, мастер по ремонту, юрист), сейчас ищет через сарафан или объявления без проверки. Profi.ru предлагает каталог специалистов с верификацией и отзывами только после выполненной работы.**

| Поле | Запись |
|---|---|
| Объект | Profi.ru: маркетплейс услуг с моделью платных откликов для специалистов. |
| Роль / buyer | Специалист (исполнитель услуг); заказчик оплачивает работу напрямую. |
| Ситуация | Специалисту нужен стабильный поток заявок; заказчику — проверенный исполнитель. |
| Работа / потеря | Не терять время на поиск клиентов/исполнителей и не попасть на недобросовестного. |
| Current alternative | Сарафан, Авито Услуги, Яндекс Услуги, YouDo, прямые договоры. |
| Claim объекта | Крупнейший каталог проверенных специалистов; платные отклики окупаются потоком заказов. |
| Unit of value | Оплаченный отклик специалиста на заявку. |
| Риск, который хотят принять | Удержание специалистов при росте стоимости откликов и конкуренции площадок. |
| Входные источники объекта | profi.ru (каталог, счётчики специалистов), отзывы otzovik (сентябрь 2026), независимые обзоры. |

## Границы

- Не является объектом исследования: кадровое агентство или фултайм-рекрутинг.
- Private data недоступны: выручка, конверсия откликов, retention специалистов, ARPU.
- Что видно снаружи: счётчики специалистов/услуг, тарифы подписок (если публичны), живые отзывы покупателей откликов.
