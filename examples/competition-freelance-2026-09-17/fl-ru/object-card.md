# Object card — FL.ru

## Исследовательская единица

> **Профессиональный фрилансер (разработчик, дизайнер, копирайтер) / заказчик проектных задач** в ситуации «нужен исполнитель под проект среднего/крупного чека или нужно получать заказы с портфолио» пытается **найти заказчика/исполнителя с гарантией расчёта** и сейчас использует **Kwork, Weblancer, Freelance.ru или прямые каналы**. FL.ru предлагает **проектную биржу 2005 года с Безопасной Сделкой (эскроу), PRO-аккаунтом и платными откликами**.

| Поле | Запись |
|---|---|
| Объект | FL.ru — проектная биржа фриланса (заказы, конкурсы, вакансии, Магазин услуг), оператор ООО «Ваан». |
| Роль / buyer | Профессиональный фрилансер с портфолио; заказчик проектов (МСП, стартапы); закупку решает владелец/руководитель. |
| Ситуация | Проект с ТЗ, несколькими этапами и средним/крупным бюджетом; оплата post-фактум рискованна. |
| Работа / потеря | Найти исполнителя/заказчика и не потерять деньги (гарантия возврата 100% при некачественной работе). |
| Current alternative | Kwork (магазин кворков), Weblancer (5% + USDT), Freelance.ru, прямой найм. |
| Claim объекта | «Несколько миллионов исполнителей», 1 500+ заказов в день, Безопасная Сделка с возвратом 100%, «нет комиссий за пополнение/вывод». |
| Unit of value | Один выполненный проект / один оплаченный доступ (PRO, отклики). |
| Риск, который хотят принять | Удержание аудитории при росте комиссий и конкуренции магазинов услуг. |
| Входные источники объекта | fl.ru (curl 200, 2026-09-18), прайс-лист (appendix_1_price.pdf), класс `object_self_claim`. |

## Границы

- Что здесь **не** является объектом исследования: качество конкретных фрилансеров, юнит-экономика PRO-подписчиков, контент блога FL.
- Какие private data доступны с разрешения владельца: PRO-выручка, доля безопасных сделок — недоступны (owner_private `not_available`).
- Какие данные недоступны: retention фрилансеров, конверсия платных откликов.
