# Object card — Weblancer (weblancer.net)

## Исследовательская единица

> **Фрилансер русскоязычного сегмента СНГ (разработчик, дизайнер, копирайтер) / заказчик** в ситуации «нужен проектный исполнитель или заказы с низкой комиссией» пытается **заключить сделку с гарантией оплаты** и сейчас использует **Kwork, FL.ru, прямые каналы**. Weblancer предлагает **биржу с 2003 года: бесплатно для заказчиков, комиссия исполнителя 5%, безопасная сделка-эскроу в USDT**.

| Поле | Запись |
|---|---|
| Объект | Weblancer.net — фриланс-биржа, оператор ООО «Веблансер» (Днепр, Украина). |
| Роль / buyer | Фрилансер СНГ с портфолио; заказчик проектов по IT, дизайну, маркетингу. |
| Ситуация | Проектная задача с понятным ТЗ; расчёт постфактум рискован — нужен escrow. |
| Работа / потеря | Найти исполнителя/заказчика и получить оплату с гарантией. |
| Current alternative | Kwork (20/12/7,5% в рублях РФ), FL.ru (PRO + отклики), Freelancehunt (для РФ закрыт с 2022), прямые каналы. |
| Claim объекта | «2,4 млн зарегистрированных, 1,25 млн заказов, 524 тыс. положительных отзывов», комиссия 5%, escrow в USDT. |
| Unit of value | Один выполненный проект / один безопасный платёж. |
| Риск, который хотят принять | Удержание доли рынка при ограниченных платёжных каналах для РФ (USDT). |
| Входные источники объекта | weblancer.net (curl 200, 2026-09-18), обзоры ToolFox/buyhold, класс `object_self_claim` + `independent_account`. |

## Границы

- Что здесь **не** является объектом исследования: отдельные исполнители, качество арбитража в конкретных спорах.
- Какие private data доступны с разрешения владельца: завершённые сделки, вывод средств, retention — недоступны (owner_private `not_available`).
- Какие данные недоступны: оборот платформы, доля сделок с эскроу.
