# Object card — Kwork (kwork.ru)

## Исследовательская единица

> **Малый предприниматель / маркетолог / частный заказчик** в ситуации «нужна типовая услуга (текст, дизайн, настройка рекламы) здесь и сейчас, без найма в штат» пытается **получить предсказуемый результат и не потерять деньги на недобросовестном исполнителе** и сейчас использует **прямые каналы, сарафан или другую биржу (FL.ru, Weblancer, Kadrof)**. Kwork предлагает **магазин услуг с фиксированной ценой от 500 ₽, безопасной сделкой и арбитражем**.

| Поле | Запись |
|---|---|
| Объект | Kwork — маркетплейс фриланс-услуг с фиксированной ценой единицы (кворк). |
| Роль / buyer | Малый бизнес, маркетологи, частные заказчики; исполнитель — самозанятый/ИП. |
| Ситуация | Типовая услуга «здесь и сейчас», без долгого брифинга и кадровых обязательств. |
| Работа / потеря | Получить предсказуемый результат и не потерять деньги на недобросовестном исполнителе. |
| Current alternative | FL.ru (PRO + платные отклики), Weblancer (комиссия 5%, escrow), Kadrof (бесплатная доска), прямые каналы/сарафан. |
| Claim объекта | Услуги от 500 ₽, 200 000+ исполнителей, контроль качества, гарантия возврата. |
| Unit of value | Один выполненный и принятый кворк. |
| Риск, который хотят принять | Масштабирование маркетплейса: удержит ли качество при росте объёма. |
| Входные источники объекта | kwork.ru (curl 200, 2026-09-18), blog.kwork.ru, класс `object_self_claim`. |

## Границы

- Что здесь **не** является объектом исследования: отдельные исполнители Kwork, качество конкретных кворков, юнит-экономика продавцов.
- Какие private data доступны с разрешения владельца: completed orders, споры/возвраты, retention исполнителей — недоступны (owner_private отмечен `not_available`).
- Какие данные недоступны: оборот платформы, доля рынка, когортные метрики.
