# Object card — poisk-pro.ru («Биржа профессионалов»)

## Исследовательская единица

> **Мастер бытовых/строительных услуг (сантехник, ремонтник, плиточник) / частный заказчик** в ситуации «нужны платные заявки от реальных заказчиков» пытается **получить контакты заказчиков** и сейчас использует **Яндекс Услуги, Profi.ru, ремонтник.ру, сарафан**. poisk-pro.ru предлагает **базу заявок и контактов заказчиков: для заказчиков бесплатно, для исполнителей — платный доступ и статусы**.

| Поле | Запись |
|---|---|
| Объект | poisk-pro.ru — сервис «Поиск профессионалов»: база заявок/контактов заказчиков, продажа доступа исполнителям. |
| Роль / buyer | Исполнитель (мастер, частный специалист) покупает доступ; заказчик — бесплатно размещает заявку. |
| Ситуация | Не хватает потока заявок; конкуренция в выдаче Яндекса/Профи.ру высока. |
| Работа / потеря | Получить реальные контакты заказчиков за предсказуемую плату. |
| Current alternative | Яндекс Услуги (комиссия/подписка), Profi.ru (платный отклик), ремонтник.ру, сарафан. |
| Claim объекта | «Более 250 000 исполнителей по 700 видам услуг, более чем в 1000 городах РФ», «бесплатный сервис для клиентов»; Google Play — «150 000 мастеров». |
| Unit of value | Один доступ к базе заявок за период / один контакт заказчика. |
| Риск, который хотят принять | Качество базы заявок: перекрёстные заявки с конкурентов и неактуальные контакты. |
| Входные источники объекта | poisk-pro.ru — curl 403 (DDoS-Guard, зафиксировано), контакты/поисковые сниппеты, Google Play, Telegram; класс `object_self_claim` + `independent_behavior`. |

## Границы

- Что здесь **не** является объектом исследования: конкретные мастера, качество отдельных заявок.
- Какие private data доступны с разрешения владельца: подписки, конверсия заявок, retention — недоступны (owner_private `not_available`).
- Какие данные недоступны: прайс доступа (сайт за DDoS-Guard), выручка, доля рынка.
