# Object card — Kadrof (kadrof.ru)

## Исследовательская единица

> **Фрилансер-новичок без портфолио / заказчик разовых услуг** в ситуации «нужны первые заказы или исполнитель без посреднических комиссий» пытается **найти работу/исполнителя бесплатно** и сейчас использует **Kwork, FL.ru, HH-подобные доски вакансий**. Kadrof предлагает **бесплатную доску вакансий и каталог фрилансеров на контентном сайте об удалённой работе**.

| Поле | Запись |
|---|---|
| Объект | Kadrof.ru — контентный сайт о фрилансе + бесплатная биржа вакансий (kadrof.ru/work) + каталог фрилансеров. |
| Роль / buyer | Фрилансер-новичок; заказчик разовых задач; прямые работодатели с B2B-вакансиями. |
| Ситуация | Первые заказы без рейтинга и портфолио; заказчик ищет исполнителя без комиссии площадки. |
| Работа / потеря | Начать зарабатывать на фрилансе / найти специалиста без платы за посредничество. |
| Current alternative | Kwork (комиссия 20% на старте), FL.ru (PRO + отклики), job-доски (HH.ru), сарафан. |
| Claim объекта | Бесплатная биржа: «вакансии удалённой работы от прямых работодателей», «каталог фрилансеров», контент для новичков. |
| Unit of value | Один найденный заказ / одна вакансия; контент. |
| Риск, который хотят принять | Монетизация при бесплатном ядре: платные функции доступа к базе соискателей. |
| Входные источники объекта | kadrof.ru/work (curl 200, 2026-09-18), kadrof.ru, класс `object_self_claim`. |

## Границы

- Что здесь **не** является объектом исследования: статьи и курсы Kadrof, юнит-экономика фрилансеров.
- Какие private data доступны с разрешения владельца: платные подписки, конверсия вакансий — недоступны (owner_private `not_available`).
- Какие данные недоступны: выручка, retention, доля рынка.
