# Object card — Yandex AI Studio (battle 2026-09-16)

## Исследовательская единица

> **ML-инженер / продуктовый менеджер в российской компании, которой нужно автоматизировать бизнес-процесс через ИИ-агента, сейчас собирает решение на связке open-source LLM + собственного кода или покупает интеграцию у системного интегратора. Объект Yandex AI Studio предлагает платформу для сборки и деплоя агентов с инфраструктурой в РФ и соответствием 152-ФЗ.**

| Поле | Запись |
|---|---|
| Объект | Yandex AI Studio — платформа создания ИИ-приложений и агентов (Yandex Cloud / Yandex B2B Tech). |
| Роль / buyer | ML-инженер, продуктовый менеджер, бизнес-аналитик; закупку одобряет ИТ-директор. |
| Ситуация | Нужен автоматизированный процесс с данными, которые нельзя вывозить за периметр РФ. |
| Работа / потеря | Запустить и поддерживать ИИ-агента без отдельной команды инфраструктуры. |
| Current alternative | Open-source LLM + самописный код; системные интеграторы; GigaChat Enterprise / Agent Platform Just AI / МТС MWS. |
| Claim объекта | Главная российская площадка для создания и деплоя ИИ-агентов. |
| Unit of value | Один развёрнутый и используемый агент в бизнес-процессе. |
| Риск, который хотят принять | Масштабирование платформы как продукта. |
| Входные источники объекта | aistudio.yandex.ru, блог Yandex Cloud, Хабр, пресса, Yandex Cloud Marketplace. |

## Границы

Не оценивается компания Яндекс целиком, Yandex Cloud как бизнес или отдельные модели. Private data (deployed/in-use агенты, платящие аккаунты, retention) недоступны — требуется после определения gap.
