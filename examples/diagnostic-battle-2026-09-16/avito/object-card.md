# Object card — Avito (battle 2026-09-16)

## Исследовательская единица

> **Продавец МСП на Авито, которому нужно получать лиды и закрывать чаты быстрее конкурентов в выдаче, сейчас отвечает вручную или нанимает менеджера. Объект Avito предлагает продвижение (Avito Ads, x2/x5/x10 просмотры), профессиональный кабинет (Avito Pro) и ИИ-инструменты (автоответы, A-Vision, ИИ-агенты в чатах).**

| Поле | Запись |
|---|---|
| Объект | Avito — classifieds-площадка и стек коммерческих сервисов для продавцов. |
| Роль / buyer | Продавец МСП / маркетолог, закупающий рекламу и инструменты конверсии. |
| Ситуация | Места в выдаче ограничены; до 60% просмотров и заказов — на первых 10 позициях; скорость ответа влияет на ранжирование. |
| Работа / потеря | Получить лиды по предсказуемой цене и не падать в ранжировании. |
| Current alternative | Ручные чаты; CRM-интеграторы (Битрикс24/amoCRM); сторонние ИИ-сервисы для Авито; VK/Telegram. |
| Claim объекта | Продвижение и ИИ-инструменты увеличивают просмотры и конверсию; ИИ-агент закрывает чаты. |
| Unit of value | Один лид/заказ по известной цене (CPL). |
| Риск, который хотят принять | Масштабирование монетизации сервисов для продавцов. |
| Входные источники объекта | Т.ТРАФ, samreshuuu.ru, Hi-Tech Mail, обзоры обновлений Авито. |

## Границы

Не оценивается вся экосистема Авито или инвестиционная стратегия. Private data (ROI по тарифам, share чатов, закрываемых ИИ) недоступны. Материал Forbes о 12/21 млрд ₽ заблокирован капчей — не верифицирован.
