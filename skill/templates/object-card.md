# Object card — [объект исследования]

## Исследовательская единица

> **[Роль] в [ситуации] пытается [выполнить работу / избежать потери] и сейчас использует [текущий способ]. Объект предлагает [изменение результата, стоимости, риска или усилия].**

| Поле | Запись |
|---|---|
| Объект | Название продукта/услуги и конкретный offer/feature, который исследуется. |
| Роль / buyer | Кто принимает решение, использует и платит; различай роли. |
| Ситуация | Когда возникает job: событие, ограничение, момент выбора. |
| Работа / потеря | Что человек пытается сделать или чего избежать. |
| Current alternative | Что используется сейчас: DIY, incumbent, агентство, spreadsheet, ничего. |
| Claim объекта | Что именно объект обещает изменить по сравнению с current alternative. |
| Unit of value | За что платят/отдают время/данные: перенос, seat, проект, результат, подписка. |
| Риск, который хотят принять | Launch, новый сегмент, канал, цена, найм, рост. |
| Входные источники объекта | URL/документы/данные владельца с датой и классом источника. |
