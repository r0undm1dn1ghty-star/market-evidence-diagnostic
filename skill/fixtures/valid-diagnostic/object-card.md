# Object card — ExportKit

## Исследовательская единица

> **Независимый веб-разработчик, которому нужно передать небольшой сайт клиенту без ежемесячной подписки на конструктор, сейчас вручную экспортирует код или оставляет сайт на платформе. ExportKit предлагает готовый перенос в статический сайт с настройкой форм.**

| Поле | Запись |
|---|---|
| Объект | ExportKit: разовый перенос лендинга из конструктора в статический HTML. |
| Роль / buyer | Независимый веб-разработчик; клиент оплачивает разовую передачу сайта. |
| Ситуация | Клиент просит снизить recurring fee или передать сайт на свой хостинг. |
| Работа / потеря | Сохранить работающий сайт и формы без ручного переписывания. |
| Current alternative | Ручной HTML export, оставление сайта на платформе, миграционная услуга. |
| Claim объекта | Сокращает время/риск передачи сайта по сравнению с ручной миграцией. |
| Unit of value | Разовый перенос одного сайта. |
| Риск, который хотят принять | Ограниченный выход к веб-разработчикам. |
| Входные источники объекта | Демо и pricing page владельца; независимые обзоры/обсуждения категории. |

## Границы

- Что здесь **не** является объектом исследования: полный website builder или hosting service.
- Какие private data доступны с разрешения владельца: completed transfers, support time, invoices.
- Какие данные недоступны: retention и acquisition cost.
